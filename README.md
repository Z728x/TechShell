# TechShell Project
## By Dawson Benison and Collin Songy
### Overview
An C implementation of a simple command line shell. Executes command, has built in funciton cd and exit. Handles I/O redirection opereators, <, >, >>, 2>, 2>>.

# Usage
## 1. Clone the repository
```bash
git clone https://github.com/Z728x/TechShell
cd TechShell
```

## 2. Compilation
```bash 
gcc techshell.c -o techshell 
```

## 3. Run the shell 
```
./techshell 
```

## Example Commands
```bash
ls -l
cd /path/to/directory
echo "Hello World" > output.txt
```
